# Abhiman Singh - Frontend Developer Portfolio

index.html  -> content (text, sections)
style.css   -> colors, sizes, layout (colors are in :root at the top)
script.js   -> settings (top of file), menu, fade-in, hero depth effect
assets/     -> portrait.webp (your photo)

Open index.html in a browser, or use "Open with Live Server" in VS Code.

## Optional details (top of script.js, the SITE block)
WhatsApp and email links are written directly in index.html (search "wa.me" or "mail.google.com").
- linkedin, github : full profile links. Hidden until set.

## Deploy on Vercel
This is a plain static site. Put these files in a GitHub repo (index.html at the root),
import the repo in Vercel, leave Framework Preset as "Other", and deploy.
(Or drag the folder into vercel.com/new.)
